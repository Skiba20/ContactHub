# ContactHub — Менеджер контактов

## О проекте

**ContactHub** — веб-приложение для управления контактами. Пользователи могут зарегистрироваться, войти в свой аккаунт, сохранять контактную информацию, редактировать её, удалять записи и просматривать данные пользователей из внешнего API.

## Основные возможности

- Регистрация и авторизация пользователей.
- Защита страниц, доступных только авторизованным пользователям.
- Добавление, просмотр, редактирование и удаление контактов (CRUD).
- Хранение контактов в базе данных SQLite.
- Разделение контактов между пользователями.
- Просмотр подробной информации о контакте.
- Получение списка пользователей из внешнего API DummyJSON.
- Поиск, фильтрация и сортировка внешних пользователей.
- Просмотр подробной информации о внешнем пользователе.
- Обработка несуществующих страниц с помощью страницы 404.
- Адаптивный интерфейс.

## Установка и запуск

### 1. Установка зависимостей

Откройте терминал в корневой папке проекта и выполните:

```bash
npm install
```

### 2. Запуск backend

Откройте первый терминал:

```bash
node server/server.js
```

Сервер API запускается на адресе:

`http://localhost:3001`

### 3. Запуск frontend

Откройте второй терминал в корневой папке проекта:

```bash
npm run dev
```

Vite обычно запускает приложение по адресу:

`http://localhost:5173`

Откройте этот адрес в браузере.

## Работа с контактами

После регистрации и входа пользователь может управлять своей контактной книгой:

1. Создавать новые контакты.
2. Просматривать сохранённые записи.
3. Открывать подробную информацию о контакте.
4. Редактировать контактные данные.
5. Удалять ненужные записи.

Данные сохраняются в SQLite, поэтому контакты не должны пропадать после перезапуска сервера.

## Авторизация и безопасность

Пароли пользователей хранятся в виде хешей с использованием bcryptjs. Для авторизации сервер выдаёт JWT, который передаётся в HttpOnly cookie. Доступ к личным контактам ограничивается идентификатором авторизованного пользователя.

## Внешние пользователи

В приложении предусмотрен отдельный раздел для просмотра данных из DummyJSON. Пользователь может искать записи, применять фильтры, менять сортировку и открывать подробную страницу выбранного пользователя.

## Обработка ошибок

Приложение содержит страницу 404 для несуществующих маршрутов. При работе с API также следует учитывать состояния загрузки, отсутствие данных и ошибки запроса.

## Назначение проекта

Проект разработан в учебных целях для демонстрации навыков создания full-stack веб-приложения с использованием React, Node.js, Express, SQLite, маршрутизации, авторизации, CRUD-операций и интеграции с внешним API.
